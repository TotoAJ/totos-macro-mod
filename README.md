This is my macro mod for Minecraft because I'm not about to waste my time learning how to switch key binds or do a bunch of sweaty ass shit.

Just download the most recent version and drop it into the .minecraft/mods folder.

Keybinds are able to be changed under the Macros section of controls.

Default key binds:
```diff
- "R" to pearl launch into the air
- "5" to spear launch into the air and forwards (do not use 5 if a hotbar slot is bound to it)
- "[" to toggle spear launching
- "]" to toggle pearl launching
- "\" to toggle auto macing
```
